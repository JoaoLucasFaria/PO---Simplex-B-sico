# PO-Simplex-Básico
Primeira atividade da matéria de Pesquisa Operacional (2025/2 - UFSJ)

Formato de entrada:
O arquivo deve se chamar entrada.txt e deve conter a tabela inicial a ser enviada para o Simplex,
com uma linha por restrição e a primeira linha sendo a função objetivo.

Exemplo:
entrada.txt
1 2 0 0 0
1 1 1 0 4
0 1 0 1 2

Como executar:
No diretório onde o programa foi salvo, use o comando

python t.py
